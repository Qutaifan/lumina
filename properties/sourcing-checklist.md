# Property Sourcing Checklist

Before accepting a listing, confirm:

## Location
[ ] Property is in Abdoun / Dabouq / Dair Ghbar / Um Uthaina / Abdali
[ ] Neighborhood is premium or transitioning to premium

## Property Quality
[ ] Grade A or B finish (Grade C only if priced correctly)
[ ] No structural issues flagged
[ ] Photos viable for luxury marketing

## Legal
[ ] Title deed is clean (no liens, disputes, or co-ownership issues)
[ ] Owner has authority to sell (single owner or POA confirmed)

## Commercial
[ ] Price within 10% of comparable sales in the area
[ ] Owner open to negotiation (not fixed at unrealistic price)
[ ] Commission agreed: 2.5% minimum

## Listing Type
[ ] Exclusive listing secured (preferred)
[ ] If co-broker: commission split agreed in writing

## Next Steps
[ ] Professional photos booked
[ ] Property brief written (EN + AR)
[ ] Added to website
[ ] Added to lead tracker for active matching
