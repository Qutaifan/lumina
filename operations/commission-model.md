# Lumina Commission Model

## Standard Rates

| Deal Type | Rate | Who Pays |
|---|---|---|
| Buyer-side (open listing) | 2.5% | Buyer |
| Exclusive listing (seller side) | 2.5% | Seller |
| Exclusive listing (both sides) | 5% total | Split buyer/seller |
| Co-broker split | 1.25% each | Buyer |
| Developer off-plan | 3%–5% | Developer |

## Minimum Thresholds

- Minimum deal size: JOD 150,000
- Minimum commission: JOD 3,750

## Example

Deal value: JOD 400,000
Exclusive listing (both sides): JOD 20,000 commission
Co-broker (buyer side only): JOD 10,000 → JOD 5,000 to Lumina

## Payment Terms

Commission due on transfer (not MOU signing).
Written agreement signed with buyer and/or seller before viewings.
